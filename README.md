# Trading Simulator

A browser-based trading simulator built with HTML, CSS and JavaScript that allows users to buy and sell stocks, track portfolio performance and experience a live simulated stock market.

---

## Features

- 📈 Live stock market simulation
- 💰 Buy and sell shares
- 📊 Portfolio tracking
- 📉 Profit & loss analytics
- 📦 Average purchase price calculation
- 💾 Automatic saving using Local Storage
- 📝 Transaction history
- 📱 Responsive dashboard

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
